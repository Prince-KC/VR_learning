ResQnova
  ========

  Static education web app for NEB Grade 5-10 students.

  How to use:
  1. Unzip this archive.
  2. Open index.html in any modern browser.

  Files included:
  - index.html              Sign in
  - grades.html             Grade selection
  - subjects.html           Subjects (Science, Math)
  - science.html            Science branches (Physics, Chemistry, Biology)
  - subject-detail.html     Theory / Labs choice (per Science branch)
  - theory.html             Chapter list (changes by ?branch= or ?subject=)
  - labs.html               Practical labs (changes by ?branch=)
  - lab-detail.html         Single lab view
  - chatbot.html            AI tutor UI
  - css/style.css           All site styling

  Note: chatbot.html requires the Gemini-backed /api/chat backend to work.
  Without the backend, all other pages still work as a static site.
